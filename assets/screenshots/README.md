# Screenshot checklist

Add only screenshots made with synthetic or deliberately prepared demo data.

Recommended files:

| Filename | Capture | Suggested crop |
|---|---|---|
| `dashboard.png` | Stats, subject progress and weekly schedule | 1600 × 1000 |
| `study-plan.png` | Generated blocks and time controls | 1400 × 1000 |
| `study-session.png` | Timer and one representative question | 1400 × 1000 |
| `past-papers.png` | Paper grid with several synthetic attempts | 1400 × 1000 |

Before committing, check that no image contains:

- a real name, email address or username;
- API keys, project references or URLs containing tokens;
- real study records or uploaded documents;
- browser bookmarks, unrelated tabs or notifications;
- copyrighted past-paper questions beyond what is necessary to demonstrate the interface.

Use PNG for crisp interface text. Keep all screenshots in this folder so the paths in the main README remain stable.
